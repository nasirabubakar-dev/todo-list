# Todo List

A simple and interactive todo list application built with HTML, CSS, and JavaScript.

## Features

- Add tasks
- Complete tasks
- Delete tasks
- Interactive task management
- Responsive design

## Technologies

- HTML
- CSS
- JavaScript

## Purpose

This project was built to practice DOM manipulation, JavaScript events, functions, and application logic.
